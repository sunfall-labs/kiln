# Native Sharding deadline attribution

Both the unsampled replay and the sampled replay of the unchanged pinned `cluster/Sharding` test recorded 60 passes and the same six failures out of 66 original case IDs. Each failure is the original 5,000 ms deadline; no assertion mismatch or inventory gap was reported. The sampled native child exited 1 after 54.420 seconds; sampler handle 6923 exited 0. Source is frozen compiler `22e662a6f40f1260e9763b23055fa7a17f7f4eda`, preceding the array, key-classification and Proxy repairs. This is diagnostic evidence under concurrent work, not final acceptance or a quiet benchmark.

The profile has 5,137 native CPU samples, 2,987 within the six failed arrival intervals. Each failed interval spans about five wall seconds with 467–513 CPU samples at 100 Hz, indicating sustained runnable work rather than an idle wait. Arrival intervals include hooks/setup/cleanup and preceding asynchronous work; counts alone cannot distinguish slow progress from a busy loop.

The stripped and warm-relinked symbolized executable have identical complete `.text` address, length and SHA-256, checked by `symbolize.py`. `receipt.json` records both executable hashes, the section proof and terminal handles. The original sampler sidecar is preserved. The derived table uses the matching symbolized executable's `nm` addresses/lengths; repeated compact static names (`ku_*`) include their address so the analyzer does not conflate different translation units. Executables stay in owned scratch storage.

Failed-interval leaves include module `d26041571cf61f0bad70365407312980` function 77 (135 samples), key hashing (91), nursery lookup (84), own-property lookup (75), and boundary conversion (69). Dynamic closure/method dispatch surrounds much of the work, as do timer callbacks. Inclusive enclosing functions are not direct cost attribution. Recomputing both seeded FNV-1a path hashes using `identity.rs` maps `d26041571cf61f0bad70365407312980` to `source/packages/effect/src/cluster/Sharding.ts`, `9f9747a19882905c65626196c02048b1` to `source/packages/effect/src/internal/effect.ts`, and `89c388d3debac598873998615b79b2a1` to `source/packages/effect/src/Scheduler.ts`. Anonymous closure indices still need IR/source provenance before attributing them to a specific source function or changing scheduling/compiler tiers.

The original 976-second build was cold for many module objects and is not directly comparable with older survey builds.
