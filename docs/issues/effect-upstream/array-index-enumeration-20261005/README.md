# Array indexed descriptor enumeration repair

The native diagnostic survey reported duplicate numeric properties while Chai compared the Scope finalizer arrays. Native `own_keys` previously emitted dense array indices and then appended indexed descriptor overlays as separate named properties. The repair makes the index walk own indexed enumerability and ordering, includes enumerable accessor holes without executing getters, and excludes canonical indices from the trailing named-property walk. Noncanonical numeric-looking names remain named properties. The existing all-own-key path is unchanged.

The focused emitted-C fixture `array_index_enumeration_merges_descriptor_overlays_once` passed (one selected test, zero failures, 1.49 seconds execution) on 2026-10-05. The complete build/test log is retained.
