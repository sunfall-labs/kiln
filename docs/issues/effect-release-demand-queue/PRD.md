# Coalesce pending module-selection work

Status: ready-for-review

The release graph-demand fixed point repeatedly queued the same module before its next visit. A warm TxHashSet build retained all 241 modules but visited them 2,477 times in one selection pass. 2,124 consecutive visits had exactly the same export-slot seed and namespace-demand state. Across five fixed-point passes, repeated `executable_demand` calls dominated emission time.

A pending-module queue deduplicates only while a path is waiting. Demand remains monotone, and a pop removes the pending mark before processing, so new demand during or after a visit schedules another pass. The selector still reads current export slots and namespace requirements at each pop; no analysis result is cached across revisions.

Validation on the pinned Effect commit `67ba4e46a11ccda0b6761578bfd22c04ae00167d` used the unchanged `TxHashSet/entry.ts` in the canonical combined-final workspace. The final candidate passed all 30 native-release cases with no skips or failures. The five kiln-liveness unit tests passed, including the regression where an escaping namespace broadens a provider that was already visited for a partial namespace. Generated C, application object, prelude, runtime, launcher, and executable were cache hits; generated C stayed 185,611,443 bytes and the executable SHA256 matched the unmodified baseline (`829f468e3c69eda8ad8ab90db5ef4bf3810f462db7d3ddd1635bfcd476a20c4b`).

Diagnostic queue counts fell from 2,477 to 349 pops in the first pass (2,128 pushes coalesced), then from 2,287 to 345, 2,262 to 346, and 2,261 to 346 in later passes. The final warm stage trace reported 76,775 ms for selection, member analysis, and release DCE; an earlier unmodified warm trace reported 124,009 ms for that aggregate. These are directional readings from different shared-machine load conditions, not a controlled benchmark. The queue-count trace, complete stage logs, native run envelope, source entry hash, compiler/provider identities, and binary hashes are retained beside this file.
