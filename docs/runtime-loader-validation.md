## Loader behavior

The graph keeps literal Node loader provenance closed-world: each retained runtime request is
identified by its owner module, captured importer path, and literal specifier. Computed or
unsupported requests remain runtime failures that can be caught by the program; they are not
guessed into graph edges. `createRequire` captures an immutable importer, normalizes a file URL to
its `href` before crossing the host boundary, and resolves CommonJS targets through the graph's
canonical cache cells.

Demand-only TypeScript builtins use the same canonical graph value path as imported builtins.
Evaluation recursively materializes retained TypeScript builtin dependencies and has a cycle
guard after existing CommonJS/cache/materialization checks, so CommonJS cycles continue to expose
partially initialized shared exports. Thrown values and loader failures stay realm-local. Runtime
failure lookup is owner-scoped and keyed by the captured importer plus literal specifier.
