# kiln npm-package compatibility — full corpus run (360 packages), 2026-09-30

Methodology mirrors porffor's dashboard: one small smoke test per package using
its real API, run under Node for expected stdout, compiled with
`kiln --one-shot run --native`, binary stdout compared byte-for-byte.

**Smoke tests are kiln-authored** (porffor's are not published). Tests live in
`tests/`, harness in `run-eval.sh`, per-package log in `results/full-run.log`,
machine-readable results in `results/full-results.tsv`.

- kiln: `~/workspace/kiln`, branch main, release build 2026-09-30 (~06:38 UTC)
- Node v24.20.0 baseline, npm 10.9.4
- Env: `CARGO`/`RUSTC` exported (native backend needs them, not just PATH);
  `TMPDIR` pointed at the eval dir (`/tmp` is a 512MB tmpfs, backend stages ~2GB);
  sequential runs, 600s per-package timeout.

## New kiln gaps found (not previously recorded)

1. **`String.prototype.toLocaleLowerCase/toLocaleUpperCase` unimplemented**
   in native backend — kills camelcase, title-case, change-case (clean refusal).
2. **Native backend refusals: 33×**, top operations: `GetProperty` (11),
   `CallMethod` (8), `Call` (4), `New` (3) — i.e. dynamic dispatch shapes the
   native emitter can't prove, including `FinalizationRegistry` construction
   (pino) and `CallMethod` on unprovable receivers (picomatch, toml, just-diff).
3. **Unsupported native emission: 19×** — e.g. `has_await_expression` imported
   across a module cycle (svelte), `parseArray` across a cycle (smol-toml).
4. **Module graph failures: ~11×** — "Cannot find module './impl/format'"
   (jsonc-parser: extensionless relative import), 'hookable' self-import,
   'tls' (ws), `node:fs` `writeFile` not materialized (yargs).
5. **Regex**: `ansi-styles` — "Invalid regular expression" at compile time.
6. **Memory**: `moment` — native binary OOMs ("out of memory").
7. **Timeout**: `prettier` exceeded 600s in native run.
8. **C toolchain**: one native link failure ("native toolchain failed: C comp…",
   truncated in log).
9. **Uncaught TypeError cluster: 24×** — several with poor diagnostics
   ("a undefined is not a function", "a object is not a function").

## Where kiln is ahead

37 of porffor's 88 missing-API packages pass under kiln (react, react-dom,
uuid, bcryptjs, pako, ky, lru-cache, debug, wrap-ansi, …); 61 of porffor's 100
runtime-error packages pass (lodash family, ajv, babel parser/generator,
vue, xstate, ramda, immer, dayjs, …); 36 of 44 wrong-output packages pass
(crypto-js, md5, decimal.js, js-yaml, yaml, …). Unicode/regex/float formatting
is broadly solid — including `\p{L}` property escapes and `matchAll`.
