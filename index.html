01 / COMPILE

Ahead of time.

Your program becomes native code through C. The compiled binary runs without a JavaScript engine inside it.

02 / ITERATE

Keep the quick loop.

Use kiln run while you work. Build an executable when you’re ready to test or ship the native version.

03 / BUILD

Familiar foundations.

ESM, CommonJS, async functions and core node:* APIs. A Rust runtime built on Tokio and Hyper supports your application.

FROM SOURCE TO BINARY

TRY IT YOURSELF

Start with one small program.

Install kiln, save the example above as hello.ts, and choose your workflow.

01 / INSTALL
curl -fsSL https://github.com/sunfall-labs/kiln/releases/latest/download/install.sh | sh
02 / RUN IMMEDIATELY
kiln run hello.ts

The interpreter is included. No C compiler needed.

03 / BUILD AN EXECUTABLE
kiln build hello.ts
./hello

Have Clang, GCC, cc or Zig on your PATH. The first native build populates the built-in library cache and may take a minute or more.

EARLY, AND MOVING

Built in the open.
Tested against real programs.

v0.1.0 is kiln’s first release. Compatibility is still evolving: try your program, check its behavior, and tell us what breaks.

Language behavior is checked against Test262. Native output is compared with the interpreter, and real library bundles exercise both engines.

Release binaries are available for macOS Apple Silicon and Linux x86_64. Linux arm64 is a follow-up. Programs run with your user account’s permissions.
