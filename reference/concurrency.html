Types, cores and ownership.

Runnable TypeScript examples for kiln’s parallel methods, typed actor calls and shared immutable graphs.

Save the downloaded examples together with package.json, which declares the project as ESM. This module setting is needed for these native TypeScript actor examples in v0.1.0.

Parallel callbacks with a checked fallback.

parallel.tsDownload ↓
type Row = { quantity: number; price: number };
const rows: Row[] = [
  { quantity: 3, price: 40 },
  { quantity: 2, price: 80 },
  { quantity: 1, price: 15 },
];
const totals: number[] = rows.parallelMap(row => row.quantity * row.price);
console.log(totals.parallelFilter(total => total > 100)); // [120, 160]
kiln check --explain-parallel parallel.ts
kiln run parallel.ts
kiln run --native parallel.ts

The compiler proves which callbacks have no observable side effects. Native execution can distribute substantial independent work over scheduler lanes. Getters, I/O, random state, clocks and unproven calls can keep execution sequential. A runtime guard or a small workload can also keep a proven call inline. This tiny example demonstrates semantics, not a measured speedup.

Typed calls to isolated state.

counter.tsDownload ↓
import { Actor } from 'kiln:actors';

export class Counter extends Actor {
  private count: number;
  constructor(start: number) {
    super();
    this.count = start;
  }
  increment(delta: number): number {
    return (this.count += delta);
  }
  readOwner(record: { readonly owner: string }): string {
    return record.owner;
  }
}
main.tsDownload ↓
import { spawnActor } from 'kiln:actors';
import type { Counter } from './counter.ts';

const owner = await spawnActor<Counter>({
  module: new URL('./counter.ts', import.meta.url),
  export: 'Counter', args: [0], mailboxCapacity: 8,
});
try {
  const count: number = await owner.ref.call('increment', [3]);
  console.log(count); // 3
} finally {
  await owner.stop();
}

spawnActor<Counter> returns a typed reference. Method names, arguments and awaited results follow Counter’s public methods. Actors own isolated realm state; a bounded mailbox limits accepted work. Native actors share a bounded scheduler rather than requiring one OS thread per actor. An asynchronous method releases its lane between turns; another call can progress when it awaits.

kiln check main.ts
kiln --node run main.ts
kiln --node run --native main.ts

For this actor, owner.ref.call('increment', ['three']) produces TS2322 and owner.ref.call('missing', []) produces TS2345 in kiln check.

Share an immutable object graph.

shared-main.tsDownload ↓
import { spawnActor } from 'kiln:actors';
import { share } from 'kiln:shared';
import type { Counter } from './counter.ts';

const owner = await spawnActor<Counter>({
  module: new URL('./counter.ts', import.meta.url),
  export: 'Counter', args: [0],
});
try {
  const record = share({ owner: 'Ada' });
  console.log(await owner.ref.call('readOwner', [record])); // Ada
  // record.owner = 'Grace'; // Type error: the snapshot is readonly.
} finally {
  await owner.stop();
}

share creates an immutable snapshot. The source remains independent. Subsequent native sends retain the graph rather than cloning its fields; the Shared type also makes nested data readonly in TypeScript.

Choose ownership deliberately.

Plain messages clone. transfer(buffer) moves an ArrayBuffer when a call is accepted and detaches the sender. prepareTransfer(value) copies a source graph into private storage, then moves that snapshot on a native handoff. isolate(factory) can move certified native heap chunks without copying when exclusive ownership is proved. The interpreter preserves move semantics by encoding and reconstructing the verified graph. Unsupported graphs and ownership failures raise DataCloneError.

These are kiln-specific APIs that reduce the application machinery around workers and serialization. Other runtimes have workers and transfer mechanisms too; these diagrams describe kiln’s design, not benchmark wins. Actor bootstrap has memory and latency costs, and application capacity needs measurement.
