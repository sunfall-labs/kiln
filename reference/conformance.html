The committed Test262 baseline records 97,178 passing and 5,072 failing variants across 122 chunks. Its stored pass/fail denominator is 102,250; unsupported and skipped outcomes are not represented here. The corpus pin is 771005236e88a909635104e03ba12559688c0172.

How to read this evidence

This is the committed v0.1.0 reference, not a fresh complete-corpus run. A regression gate compares individual chunks so gains in one area cannot hide losses in another. Routine Test262 runs defer the reviewed extended cases; full runs include them. Test case variants are not counts of language features or supported npm packages.

Native probes compare execution modes, while the thirdparty runner compares real bundle outputs with Node. A language baseline, engine parity check and library check each answer a different question.

mise run gate        # routine correctness and parity
mise run gate-full   # also extended cases and postcss performance
mise run test262-full
