The committed 2026-10-11 run compares compiled native programs with Node v26.8.1, using the native-dev profile and --node host mode. Every recorded package smoke test prints the same bytes as Node.

The inventory includes Zod, ArkType, Effect, Express, Lodash, Prettier, @babel/core and TypeScript. These are real installed packages at exact versions, exercised through small tests with typically 3–8 API calls each. Passing a smoke test does not mean the package’s entire upstream suite passes. The TypeScript npm package row is separate from kiln check’s TS7 diagnostic evidence.

What the runner measures.

  1. Install the pinned npm dependencies and run the test under Node for expected stdout.
  2. Compile the same test with kiln’s native backend and the Node host.
  3. Execute the resulting binary and compare stdout byte for byte.

Compiler errors, runtime errors, wrong output and timeouts are separate outcomes. Recorded wall times include compilation or process startup and are not warmed throughput benchmarks. The corpus is informational and runs separately from mise run gate; --require-pass enables explicit acceptance.

The recorded development-profile result does not establish production-profile acceptance. Under NODE_ENV=production, the original warning smoke expects development logging and fails its Node oracle. That result remains visible rather than being counted as a pass.

Use existing packages in a native build.

npm install zod
kiln check app.ts
kiln run app.ts
kiln build app.ts
./app

kiln uses Node-style package resolution for ESM and CommonJS. Importing a Node built-in, or having package.json, tsconfig.json or node_modules in the project, selects the Node layer automatically; --node forces it. npm installs dependencies; kiln runs and compiles the program.

For module paths selected at runtime, declare the possible modules in the project’s package.json so a native build includes them. These entries resolve from the package root and run only when requested:

{"kiln": {"include": ["./src/worker-task.cjs", "pino/file"]}}

Reproduce the recorded profile.

cd conformance/npm-compat
npm ci
cd ../..
env -u NODE_ENV python3 conformance/npm-compat/runner.py \
  --kiln /absolute/path/to/kiln \
  --raw /absolute/path/to/fresh-results \
  --profile native-dev --require-pass
