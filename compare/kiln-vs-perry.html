kiln vs Perry: TypeScript to Native Compared

Compare kiln and Perry for TypeScript checking, native binaries, npm projects, concurrency and native UI. Practical differences with linked source evidence.

kiln v0.1.0 · upstream documentation reviewed October 12, 2026

Two routes from TypeScript to an executable.

kiln and Perry both let you ship a native binary from TypeScript. Perry uses SWC and LLVM and documents a broad platform UI offering. kiln focuses its v0.1.0 workflow on checking source, running it immediately, then compiling the program for macOS Apple Silicon or Linux x86_64. Type checking and compiler compatibility are different checks.

Perry’s CLI separates compatibility scanning with perry check from TypeScript checking through --type-check and tsgo. Perry command semantics.

kiln’s embedded kiln check reports source diagnostics with TypeScript 7.0.2 declaration inputs. The release record has 11,980 exact reference-output matches out of 13,101 cases, plus 1,710 matches out of 2,226 differential cases. This makes the remaining diagnostic differences inspectable; it does not establish complete TS7 equivalence. Checker commands and compatibility evidence.

Compare how values cross cores.

Perry documents parallelMap, parallelFilter and spawn, with copied object values and restrictions on mutable captures. Perry’s threading and transfer model.

kiln’s collection methods use compiler effect proofs and sequential fallbacks. For stateful components, typed actors own separate realms and bounded mailboxes. Shared immutable snapshots let subsequent native sends retain a graph instead of cloning its fields. These APIs offer different ways to organize work; neither API shape alone predicts throughput. Typed concurrency and ownership examples.

Which should you evaluate first?

If your requirement is a wider native UI target set, compare Perry’s platform guides with kiln’s narrower released GUI provider. If you want one interpreter-to-native workflow with visible source-checker evidence, Node-oriented package tests and typed actor ownership, start with kiln’s runnable reference examples.

Both need validation against your actual dependencies. kiln records 361/361 passing pinned npm smoke tests in native-dev mode, not complete upstream package suites. Package names, versions and test scope. Perry also documents Node and npm support; this page does not compare their percentages because the corpora differ. Perry’s compatibility overview.
