Native TypeScript and JavaScript tools differ in more than their compilation backend. Source diagnostics, host APIs, module loading, ownership and target platforms determine how much of your existing application can move with you.

kiln combines an immediate interpreter with native builds, source TypeScript checking, Node-style package resolution and typed concurrency APIs. These pages compare that workflow with the documented approaches of other native compilers.
